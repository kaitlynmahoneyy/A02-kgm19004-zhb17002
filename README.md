We use the California Housing Dataset from scikit-learn for this project. We build a neural network by using MLPRegressor with early stopping enabled to predict house prices and generate a scatter plot to compare our predictions with actual values. We also work together to be familiar with how to use the GitHub platform. We create new branches, send PR requests, then review each other’s code and merge the branches back to main.

We completed the following task for this project:
1. Download the California housing data and split it into train, validation, and test.
2. Created a box plot for variable MedHouseVal.
3. Build a neural network using two hidden layers and predict the house price.
4. Creating the scatter plot to compare our prediction with the actual value and save the plots.

Output: The script generates four figures saved to the `figures/` folder:
* `MedHouseVal_boxplot.png` - Distribution of median house values.
* `train_actual_vs_predicted.png` - Model performance on training data.
* `Validation_actual_vs_predicted.png` - Model performance on validation data.
* `Test_actual_vs_predicted.png` - Model performance on test data.
